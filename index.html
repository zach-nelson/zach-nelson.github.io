Things I've built

  • flooded-acreage

    Sentinel-2 satellite threshold analysis for flood mapping

    Why: Valley-scale flood monitoring needed fast, repeatable observations to track inundated acreage by management unit

    What changed: Replaced manual field surveys with automated NIR threshold analysis, generating unit-by-unit reports and maps from satellite imagery

    Tools: Sentinel-2, Earth Engine, NIR band thresholding

    github.com/zach-nelson/flooded-acreage

  • pumping-management

    Soil-plant water balance and groundwater pumping models

    Why: Groundwater pumping decisions needed to balance extraction with ecosystem impacts

    Tools: Hydrological modeling, soil-plant water dynamics, groundwater extraction analysis

    github.com/zach-nelson/pumping-management

  • Automated reporting pipelines

    Reproducible analysis and report generation workflows

    Why: Data compliance reporting consumed weeks; manual copy-paste introduced errors and made methods opaque to reviewers

    What changed: Automated data ingestion through final report delivery; methods became auditable, updates became trivial

    Tools: R, targets, Quarto, R Markdown, functional programming patterns

  • Geospatial decision support applications

    Interactive mapping and data exploration tools

    Why: Field staff and decision makers needed immediate access to monitoring data and habitat models without GIS expertise

    What changed: Browser-based tools let stakeholders query spatial data, compare scenarios, and export results without technical staff as intermediaries

    Tools: R Shiny, ArcGIS Online, ArcGIS Enterprise, Python, web mapping APIs
